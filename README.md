## 2. 임시 배정 내역 (운용 및 확정 전 필수 확인)

### 2-2. 확정 전 `(안)` 및 초안(A30) 안내
- **A30 내부 작업 디바이스**: `M1540~M1800`대, `D1540~D1999`, `T1501~T1536`은 `ladder_alloc_v6.csv`의 **초안** 배정입니다.
- **Factory I/O I/O 번지 `(안)`**: 아래 표에서 `(안)` 표시가 된 `X`/`Y`/`D` 번지는 `fio_io_map_v6.csv` 기준 잠정 번지이므로 설비 결선 변경 시 함께 수정해야 합니다.

## 3. 미구현(주석 처리) 항목 — 시운전 전 필수 조치

현재 코드에는 설계서 상 미결정 안건 3건이 주석(`;`)으로만 남아 있습니다.

1. **`A09 <A27>` 크레인 목표 칸 변환표 (`COMMON_RACK.il` 27행)**
   - 내용: 첫 스캔(`SM402`) 시 `D1870~D1893` (랙 R01~R24)에 Factory I/O 크레인 목표 칸 번호(1~54)를 `MOV`로 초기화하는 회로가 미구현입니다.
   - 영향: 현재 상태에서는 크레인 A/B가 `D1601`, `D1602`에 `0`을 출력합니다.
2. **`C06 <A28>` 팔레트(Base) 값 (`MC_MAIN_PROCESS.il` 158행)**
   - 내용: `LD= D1541 K5`일 때 `D1509`에 팔레트 번호를 넣는 코드가 미구현입니다.
3. **`C09 <A26>` 박스 크기 판별 회로 (`MC_MAIN_PROCESS.il` 164행)**
   - 내용: 박스 크기(`D1519` 등)와 DB 셀 수(`D1518`)를 비교해 일치 시 `M1543`을 ON시키는 회로가 미구현입니다.
   - **중요**: 시뮬레이션 시 외부에서 **`M1543`을 강제로 ON**하지 않으면 STEP 01(`D1541=K10`)에서 `M1951`(박스 크기 불일치 알람)이 발생하며 `D1541=K15`에서 멈춥니다.

## 5. 운영 및 시뮬레이션 시 주의사항

1. **비상정지(`X1500`) 접점 극성**: `COMMON_RACK.il`에서 `LDI X1500 -> OUT M1500`으로 작성되어 있으므로, **정상 운전 시 `X1500`이 ON(1)** 상태여야 비상정지가 풀립니다.
2. **운전 시작 및 `MC N0` 정지 특성**: `X1501`로 `M1950`이 `SET`되면 `MC_MAIN_PROCESS`가 실행됩니다. 정지(`X1502`) 또는 비상정지(`M1500`) 시 `MC N0` 내부의 `OUT` 코일(컨베이어·스토퍼·포크·리프트·프로브 등)만 OFF되며, 스텝 번호(`D1541`, `D1640` 등)와 랙 데이터(`D1660~`)는 유지되므로 재시작 시 멈춘 스텝부터 이어집니다.
3. **시연용 타이머/설정값**: 랙 숙성 시간(`COMMON_RACK.il` `K16` = 16초)과 빈 칸 LOCK 자동 해제 시간(`K20` = 20초), 각종 타이머 `K`값은 시뮬레이션 시연값으로 설정되어 있으므로 실설비/Factory I/O 연동 시 조정이 필요합니다.
