## 맞춘 값과 이유
| 항목 | 값 | 이유(시험) |
|---|---|---|
| 크레인 A · B X 보정 | 각 −1u | A 0: 랙 보에 걸림 · A +2: 주행 막힘 · A만 −2: B가 들다 낙하 |
| 크레인 칸 번호 | 칸 = (단−1)×9 + 열, 열 1 = 각 크레인 입출고점 쪽, 같은 칸 B 열 = 7 − A 열 | A1↔B6 · A2↔B5 확인 |
| 입고점 도착 `X1512` | 크레인 쪽 끝 1u 안, 켜지면 즉시 정지 | 가운데 + 1.5초 더 돌리면 포크에서 기울어 박스 낙하 |
| 라인 부품 | 입고 · 출고 모두 롤러, 분기 CT, 재검사 모퉁이 Curved Roller(CCW, 입구를 들어오는 롤러 가운데에) | 벨트 ↔ 롤러 경계 4가지 방법 모두 실패(박스 낙하 · 정체). CW면 곡선이 팔레트를 되밀음 |
| 받침 | Square pallet (`D1509` = 2) | 긴 Pallet은 CT보다 길어 옆 이송 불가 |
| CT 옆 이송 | 3번째 태그 (Left) = 흐름 왼쪽(+Z), 4번째 (Right) = 오른쪽(−Z). CT 위 센서는 하류 끝(+3u), 감지 즉시 굴림 정지 | 늦게 멈추면 하류로 밀려 모서리에 걸림 |
| 합류 | 합류 롤러로 CT4 가장자리까지 밀고 → CT4 체인을 올려 2.6초 끌어옴 → 굴림 | 체인을 먼저 올리면 4 cm 턱에 부딪혀 틀어짐 |
| 게이트 센서 `X1900` · `X1901` · `X1902` | Remover보다 6u 이상 앞 | 붙어 있으면 지워진 뒤라 신호 없음 |
| RFID ①②③ | Roller Stop 막대 5u 앞(팔레트 가운데), 라인에서 4u, Y5, FineRotation −89.75(사용자 자세). ③은 +Z 쪽 | 시리얼은 읽힘, Status는 아래 표 |
| 높이 센서 `X1511` | 기둥, Y5 (사용자 맞춤) | Y8이면 Large만 감지 |

## Roller Stop (11-23 오후 해결)
- 자세: 막대가 흐름을 가로지름(ROT 0), 높이 Y3 → 내리면 롤러 높이, 올리면 롤러 위로 나옴(화면 확인). ROT 1은 흐름과 나란해 막지 못함(전에 방향을 거꾸로 판단했음).
- 정위치 센서는 막대 3u 앞, RFID는 막대 5u 앞(팔레트 가운데). 센서가 막대에서 멀면 서 있어도 센서가 꺼져 "통과"로 오판했음.
- 결과: RFID ① · 메인 검사 · 재검사 3곳 모두 정지 유지 → 내리면 통과 (재검사 NG 경로 152.9초 통과).

## RFID 읽기 (리더 높이 · 자세별, Square pallet)
| 자세 | Small box | Large box |
|---|---|---|
| 세움 Y4 | Status 1 (팔레트 시리얼만) | Status 1 |
| 세움 Y5 | Status 0 | Status 1 |
| 세움 Y6 · Y7 | Status 1 | Status 0 |
| 눕힘(사용자 자세, FineRotation −89.75) | Status 1 | Status 1 |
- 어느 자세든 시리얼(Read Data)은 갱신됨. ① · ② · ③이 같은 팔레트에서 같은 시리얼(6175)을 읽음 → 추적 가능.
- 재검사 RFID ③은 곡선 롤러를 지나 팔레트가 90° 돌아 라인 반대쪽(+Z)에 둬야 시리얼을 읽음.
- Status는 박스 크기 · 위치에 따라 0/1이 갈림 → 래더 B1~B3(Status 0 판정)과 안 맞을 수 있음.

## 안 된 것 / 남은 것 (안건 A31)
- RFID 판정: **시리얼 변화로 결정(11-23)**. Status 1이어도 쓰기 · 읽기 정상 확인(Large 쓰기 1234 → 읽기 1234, Small 4321 → 4321). 래더 설계서 · 치환 목록 반영 완료. HMI 14장 RFID 알람(`D1514` 등 ≠ 0)은 HMI 쪽에서 바꿔야 함.
- 번지 없는 CT 출력(`M1720` 직진 · 2차 분리 직진 · 합류 CT 굴림/체인)과 래더 K · P · Q 블록의 CT 순서 반영.
- GX Works2 래더 입력 미착수.
