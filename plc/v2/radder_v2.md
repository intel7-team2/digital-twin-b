# 래더 작성 규칙 (MELSEC-Q, GX Works2, 스텝 최소화)

## 1. 기본 전제

* 대상: MELSEC-Q 시리즈 / GX Works2 / 래더. Q 시리즈 명령어만 사용(ZRST, M8002 등 FX 전용 금지).
* 우선순위: 안전(비상정지·인터록) > 사양 충족 > 가독성 > 스텝 수.

## 2. 조건 중복 제거

* 같은 조건의 출력은 한 렁에서 출력 분기로 묶는다.
* 부울식을 정리한 뒤 래더로 옮긴다. (A·B + A·C → A·(B+C))
* 3개 이상 겹치는 공통 조건은 공통 조건용 M 1개로 묶어 각 렁에서 참조한다.
* MC/MCR는 사용 금지(SET된 디바이스가 MC OFF 때 유지되므로).

## 3. 중간 릴레이 제한

* 한 번만 참조되는 M은 만들지 않는다. X를 M에 그대로 복사하는 렁도 금지.
* 상시 ON은 SM400, 첫 스캔은 SM402를 쓴다.
* 예외(허용): 2곳 이상에서 참조하는 경우, 한 줄 접점 수 한계를 넘거나 분기가 과도하게 중첩되는 경우, 사양서에 HMI 표시용 등으로 M 영역이 지정된 경우.

## 4. 명령어 선택

* 에지는 LDP/LDF/ANDP/ANDF/ORP/ORF를 1순위로 쓴다. 같은 펄스를 2곳 이상에서 쓸 때만 PLS/PLF를 허용한다.
* 여러 조건을 합친 결과를 펄스로 만들 때는 MEP/MEF를 쓴다.
* 워드 1개(16비트) 클리어는 MOV K0, 여러 워드는 FMOV, 비트 범위 리셋은 BKRST를 쓴다.
* KnY/KnM에 MOV를 쓰는 것은, 그 범위 전체가 해당 패턴 전용으로 연속 할당돼 있을 때만 허용한다(다른 출력이 섞여 있으면 금지).
* 32비트 명령은 값이 16비트 범위를 넘을 때만 쓴다.

## 5. 시퀀스 구조

* 구성 순서: [초기화부] → [시퀀스 제어부] → [출력부].
* 초기화부: SM402(첫 스캔)에서 BKRST로 스텝 릴레이 영역 전체를 리셋하고, 초기 스텝을 SET한다. **비상정지만으로는 리셋하지 않는다**(크레인 · 리프트가 들고 있는 팔레트 유지 — 실제 적용, `steps_v2.md`).
* (v3, 11-26) 정지 중(`M1950` OFF) 초기화 요청 `M1961`이 들어오면 첫 스캔과 같이 리셋한다. 이때 스텝 밖의 구간 점유 · 판정 넘김 비트와 알람 `M1951~M1957`도 함께 지운다(논의 문서 15-18).
* 시퀀스 제어부: M 스텝 릴레이를 SET/RST로만 제어한다. 다음 스텝을 SET하는 렁에서 현재 스텝을 RST한다.
* 스캔 관통 방지: 스텝 렁은 역순(큰 스텝 번호를 위쪽)으로 배치하거나, 전환 조건에 에지 명령을 쓴다.
* 출력부: Y는 SET/RST 금지. 해당 스텝 M 접점들을 병렬로 묶어 OUT Yx 하나로만 출력한다(이중 코일 금지).
* 비상정지·인터록은 출력부에 직렬로 넣고, 스텝 절감 대상에서 제외한다.

## 6. 사양에 없는 것 추가 금지

* 동작 설명서와 I/O 할당표에 없는 알람, 디버그용 릴레이, 카운터는 넣지 않는다. (알람 `M1951~M1957` · 알람 확인 `M1960` · 초기화 `M1961` · 노랑 경광등 `Y1692`는 배정표 · 번지 안에 있는 사양 항목)

## 7. 작업 방식과 보고

* 초안은 파일에 작성하고, 2~6번 규칙으로 스스로 검토·수정한 최종본만 남긴다.
* 최종 산출물: GX Works2에 붙여 넣을 수 있는 순수 IL 텍스트 파일, 렁별 명령어 수와 스텝 추정치 표(추정치임을 표시).
* 보고: 적용한 절감 내역(제거한 중복 조건, 중간 릴레이 등)을 3~5줄로 요약한다.
* 실제 스텝 수는 GX Works2에서 변환해 확인한다.
